[ 01 — O QUE É ESTE PROJETO ]

POR QUE
VOIDEN EXISTE.

VOIDEN nasceu como um exercício de construção de marca do zero: essência, posicionamento, paleta, tipografia, sistema gráfico, direção fotográfica e arquitetura de conteúdo — tudo pensado como se fosse um streetwear independente real.

A partir desse branding, o projeto evoluiu para um site completo, desenvolvido para simular a experiência de uma loja/drop underground: home, produtos, editorial, arquivo e manifesto.

O objetivo é demonstrar, em um caso só, a ponte entre identidade visual e front-end — como uma personalidade de marca (fria, minimalista, provocativa) se traduz em decisões concretas de layout, tipografia, movimento e fotografia.

Serve como peça de portfólio para apresentar processo criativo completo: da estratégia de marca à interface funcional.
